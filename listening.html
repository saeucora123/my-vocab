// NEURO-ECHO OPERATIONAL MANUAL v3.0

01. CORE PHILOSOPHY (核心理念)

  • 听写重构 (Reconstruction): 不仅仅是听，而是迫使大脑通过“预测-验证”回路重构语言流。
  • 即时反馈 (Immediate Loop): 每一个单词的校验都在毫秒级完成，利用多巴胺强化正确记忆。

02. WORKFLOW (训练流程)

  • Initialization: 在首页粘贴一段英文文本（推荐 CET-6/雅思/原版新闻）。点击 INITIALIZE 启动。
  • Blind Echo: 系统会朗读整句，你需要填入挖空的实词（动词、名词等），虚词会自动显示。
  • Completion: 全对后进入“影子跟读 (Shadowing)”模式，利用 3.5秒 模仿原声发音。

03. NEURAL CODES (视觉反馈)

  • GREEN (Solid): 完美匹配。突触连接已建立。
  • YELLOW (Dashed): 模糊匹配。拼写有微瑕（如单复数/时态错误），但系统判定听力理解正确。
  • RED (Solid): 连接中断。单词错误，请重新聆听。

04. ADVANCED TOOLS (高级功能)

  • Double Click (声学隔离): 双击任何输入框，系统将单独朗读该单词。用于攻克连读弱读。
  • Smart Tab (智能提示):
    - 按第1次：听觉提示（播放该词读音）。
    - 按第2次：视觉提示（显示首字母）。
  • Auto-Scaffolding (自适应脚手架): 如果错误率过高，系统会自动将语速降至 0.8x 或 0.6x，直到你掌握为止。

05. SHORTCUTS (键盘指令)

  • Enter : 提交检查 / 跳至下一空 / 下一句
  • Ctrl + Enter : 重播整句 (Replay)
  • Tab : 请求提示 (Hint)
  • ? (Shift+/) : 打开/关闭本手册
